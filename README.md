# Primeiro Site em HTML e CSS

Meu primeiro site, criado nos primeiros dias do curso de Análise e Desenvolvimento de Sistemas, para praticar os fundamentos do desenvolvimento web.

## Tecnologias
- HTML5
- CSS

## O que eu pratiquei
- Estrutura de uma página com HTML
- Estilização com CSS
- Organização de textos, imagens e seções

## Como visualizar
1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.

## Sobre
Este projeto marca o início dos meus estudos em programação. De lá para cá, também estudei Python, C, JavaScript, PHP e banco de dados.
